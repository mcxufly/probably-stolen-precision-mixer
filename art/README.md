# 精密配比机像素美术

## 设计

- 原生 **48×48 RGBA**，对应原版 **16px/格、3×3占格**。从48px坐标重新绘制，不把旧64px图缩小。
- 灰绿铸造金属外壳，紫灰内腔与右侧暗面；顶部和承托平台可见，保留俯视前侧透视。高光只用于短边、螺丝与玻璃口沿，不使用白色大面积反光。
- 左侧是小控制面板，中右是两个独立青色玻璃容器工位与细加料管。空态仍显示两个金属座；左工位为目标瓶，右工位为原料瓶。
- 四态依次为空 / 仅目标 / 仅原料 / 双瓶。玻璃只是固定的占用标识，不表达实际液量、成分或颜色。
- 四态尺寸和透明轮廓完全相同；9个格中心全部不透明。原生像素仅用透明/不透明alpha，无抗锯齿。

## 生成与检查

在项目根目录运行：

```sh
python3 art/draw_mixer.py
```

仅依赖Python 3与Pillow，无字体或外部图像输入。脚本直接写入四张运行时贴图及标注预览，并断言48px RGBA、16px/格的3×3尺寸、9个格中心、二值alpha和四态相同的alpha字节。

[四态预览](mixer_states.png)使用严格**4倍最近邻**（每张48→192px）；英文标注 `EMPTY / TARGET / SOURCE / BOTH` 与 `L: TARGET / R: SOURCE` 对应空 / 目标 / 原料 / 双瓶。
