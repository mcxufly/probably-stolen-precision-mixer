## Installation and validation / 安装与验证

Extract `PrecisionMixer` into the game's `Mods` folder, activate it, and restart. Replace the previous Mod files while the game is closed. Built against product version `0.46D` / Steam build `26337366`.

解压到游戏的`Mods`目录，启用并重启。替换旧版时请先退出游戏。

The user confirmed v0.1.8's chemical-module gameplay testing worked. This update changes licensing and distribution metadata; it does not imply additional manual testing of every save/load or UI scenario. Back up saves; remove bottles and dispose of all mixer machines before uninstalling. Installed modules remain locked in the machine.
