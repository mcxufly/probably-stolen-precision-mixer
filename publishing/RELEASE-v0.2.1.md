# v0.2.1 — In-game usage hints / 游戏内使用提示

Adds an English/Chinese Help button to the machine panel covering manual dosing versus automatic concentration mixing, the full chemical scanner requirement, dose rounding, permanent chemical module installation and Jackson's daily 25%/one-purchase stock policy.

Manual preview now shows requested dose, current metering step and actual rounded dose together. For example, a requested23mL at10mL resolution previews20mL rather than silently implying the full input will be added.

No gameplay-rule changes from v0.2.0. Help layout still needs in-game visual confirmation. Existing automatic tests, localization and game scanner checks apply. Not uploaded to GitHub/Steam by this local build.

新增机器面板「使用说明」按钮，中英文说明两种模式、完整化学检测仪门槛、向下取整示例、化学模组锁定和博士限购规则。手动预览同时显示设定量、计量步长与实际加入量，避免玩家误解。

本次只补充说明和预览提示，不改变v0.2.0玩法。说明窗口实际布局仍需游戏内确认。本包为本地测试版，未自动发布到GitHub或Steam。
